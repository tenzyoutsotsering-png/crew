# CREW

CREW is the social operating system for communities.

The first web prototype combines community discovery, crew spaces, participation, playful interactions, quests, events, tasks, and shared memories in one place.

## Stack

- Next.js
- React
- TypeScript
- Vercel

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Product direction

Join → Meet → Participate → Play → Create → Remember.

The web app is the foundation for the future CREW mobile experience and organizer dashboard.
